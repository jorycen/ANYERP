# ANY-ERP API 心跳客户端

这是一个独立运行在其他 Windows 电脑上的 API 保活程序。双击 EXE 后会自动开始心跳，立即执行一次查询，之后按设定间隔持续执行，并在页面中展示每次结果。

它只向后台发送：

```text
GET /api/v1/health/db
```

不连接数据库、不使用登录账号、不修改任何业务数据。

## 使用方式

将以下两个文件放在同一目录：

```text
ANY-ERP-Heartbeat.exe
heartbeat.config
```

先编辑 `heartbeat.config` 中的 `URL`，确认它是生产 API 地址。默认配置使用当前项目中的腾讯云服务地址。

直接双击 EXE 即可每 300 秒执行一次请求；日志写入同目录的 `heartbeat.log`。需要暂停时点击“停止心跳”即可。

页面中可以修改 API 地址、执行间隔和请求超时，点击“保存配置”后下次打开继续使用。

## 推荐设置

如果希望电脑开机后自动打开页面，可以在运行心跳的电脑上使用 Windows“任务计划程序”：

1. 创建基本任务，设置为“用户登录时启动”；
2. 操作选择启动 `ANY-ERP-Heartbeat.exe`；
3. 起始位置填写 EXE 所在目录；
4. 勾选“无论用户是否登录都运行”；
5. 失败时允许重新启动任务。

程序本身会持续运行，不需要任务计划程序每 5 分钟重复启动。

## 重要限制

该程序只能通过外部请求降低云 API 的空闲暂停概率。如果云平台策略不把定时访问计入活跃流量，或者平台明确禁止通过请求保活，仍需要在云托管侧开启“常驻实例/最小实例”或使用平台原生定时任务。
