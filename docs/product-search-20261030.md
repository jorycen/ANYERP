# 商品与库存统一搜索

用户确认适用于商品和库存搜索入口。空白分隔关键词必须全部匹配同一商品，可跨字段；按SN、PN、产品名称、厂商商品名称config、详细配置remark优先级，再按可用销售库存降序，商品ID稳定排序。多字段命中以最优字段定级。

后台共用productSearch，筛选与排序在分页前完成。接入商品列表、开单搜索、价格列表/导出、库存汇总及SN库存明细。SN匹配和库存排序使用权限门店范围；SN库存明细按当前行SN匹配。SN商品排序库存按有效销售仓在库SN数量，普通商品按销售仓数量。

小程序开单移除前端二次库存排序，改动仅保留sdxcx本地，不上传GitHub。本次无Web源码变更，无须重新构建Web。
