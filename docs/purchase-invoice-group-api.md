# 进项发票组登记（2026-10-29 用户确认）

## 范围与金额

Web发票管理取消销方税号输入框，按所选付款所属供应商资料读取已维护税号；缺失保存NULL，不生成虚构税号。多张只填号码，共用开票日期、票种、税率及一组金额。不同税率分组登记；无单票金额不自动平均拆分，不把组金额重复计入每个号码。

## 接口

* POST /finance/purchase-invoices/preview：传taxRate以及totalAmount，或allocations[{paymentId,amount}]。未传totalAmount时汇总本次分摊金额作为默认价税合计；返回totalAmount、amountWithoutTax、taxAmount、taxRate。不含税金额按价税合计/(1+税率)四舍五入至分，税额为合计减不含税金额，保证分币守恒。此为登记测算，实际金额由经办人核对。
* POST /finance/purchase-invoices：兼容旧invoiceNo，并新增invoiceNumbers字符串数组（1—100项）。价税合计与分摊合计一致；后台重新测算税额和不含税金额，不信任客户端税额。支付流水按ID排序加锁，保持同供应商、同经销商、有效含税正金额付款及剩余可收票校验。
* GET /finance/purchase-invoices及导出：invoice_numbers与invoice_numbers_text包含整组所有号码；主记录和付款分摊仅保存一组金额。搜索支持组中任意号码，导出不按号码重复金额。
* 原退票API退回整组，恢复原付款待收票额度。重新登记保持原整组号码，沿用主记录和审计规则；不自动拆分已退回组或合并多个旧组。

## 存储及查重

新增T_PURCHASE_INVOICE_NUMBER，只存号码与主记录归属，不存金额；原T_PURCHASE_INVOICE仍保存唯一的一组金额，invoice_no保留首个真实号码兼容旧查询。号码按经销商/供应商名称查重；有税号时增加税号/号码唯一约束。同时查原无子记录的历史单票，防止旧票绕过。所有写入口（含原Excel导入）复用号码查重服务。

原税号字段兼容改为可空；原已填税号和原唯一索引保留。部署须运行启动迁移，确认号码表和字段准备完成后才能使用新版接口；不批量重写原发票、不补造历史税号、不把历史金额拆成多个单票金额。Excel原导入格式维持原税号及单号约定。

主记录、号码、付款分摊及审计同事务；任一失败整体回滚。多号码登记、次要号码查重、整组退回和重新登记、搜索回读及审计失败回滚已用MySQL会话临时表验证；未修改生产发票或付款数据。
