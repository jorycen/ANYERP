# 通用审批中心

## 设计边界

审批流程定义、审批节点、审批人解析规则、串行签批、或签、拒绝后重新提交，均由通用审批引擎处理。

以下调整通常只需要在审批中心配置，不需要修改代码：

- 新增或停用一个流程定义；
- 调整节点顺序、节点名称和签批方式；
- 在现有审批人类型中选择固定人员、门店店长、直属上级或角色；
- 调整角色范围及门店/主体人员的审批关系。

## 何时仍需要开发

如果新增审批对应的业务单据、字段校验、审批通过后的业务动作，仍需增加业务适配器。例如审批通过后更新采购单状态、生成库存批次或写入财务凭证，这些动作不能仅靠审批节点配置安全完成。

推荐接入方式：业务模块负责保存申请单和业务状态，调用审批服务创建实例；审批服务只负责流程状态和审批记录；业务模块通过审批结果回调或查询结果完成自己的状态变更。

## 版本与数据

发布后的流程定义不可直接覆盖，修改会生成新的草稿版本。审批实例保存流程快照，因此后续修改流程不会改变已提交申请的历史审批路径。
