# 员工毛利汇总与店长分阶段提成

## API

复用 `GET /api/v1/report/employee-profit-summary` 及其 `/export`。
参数继续为 `startDate/endDate/storeId/employeeId/reportRole`；权限与原接口一致。
页面和导出读取同一个 `load`，共用后台 `columns/cells`，不在客户端计算。

## 店长阶段（2026-11-10 用户确认，覆盖月末统一套比例的旧规则）

- 每月从1日起累计全店销售端毛利，产品/运营毛利不参与。
- 以经营流水业务日期和原业务发生时间（北京时间）排序，同刻销售优先、事件ID升序。
- 超过盈亏线前的店长个人毛利按15%，超出后的按25%。
- 跨线订单按跨线前后两部分占该单毛利的比例拆分个人毛利。
- 例：盈亏线100000，已有99900，下一单1000，则该单100按15%、900按25%。
- 退货按原销售单阶段比例冲回；跨月读取原销售月份的盈亏线和冻结流水。
- 退货减少当月累计毛利，后续交易依据减少后的累计值判断阶段。
- 个人经营调整沿原单阶段计提。个人毛利金额、日期和分摊继续沿用员工绩效服务；全店跨线累计沿用财务经营流水业务日期，不改变既有统计日期契约。
- 费用扣减按两个阶段的个人毛利占比分摊，尾差归25%阶段；两阶段毛利存在负数且扣减无法归属时待核实，不猜测费用阶段。
- 先保留两阶段毛利、费用到分，再分别对两阶段扣减后毛利按15%/25%计算并舍入到分，合并个人销售提成。
- 另计全店销售端毛利3%门店提成，石高铭、唐陈为5%；与个人阶段是否可计算独立判断。
- 卢珏、葛宇继续按普通员工规则。

## 数据来源及异常

`managerCommissionTimeline` 读取现有财务经营事件和冻结单据时间，不调用价格或税费重算。
个人分摊复用 `buildEmployeePerformance` 的完整明细；看板默认100条明细限制保持，提成计算显式使用 `allDetails`。
日期只选月中时，阶段仍读取完整月份前序流水；员工及角色筛选不改变全店跨线基数。
跨月报表分月计提后相加，不对合并金额重新套比例。

以下情况返回具体单号和原因，并保留独立可计算的门店提成：原月份盈亏线缺失、原销售阶段无法追溯、跨店归属待核实、冻结销售毛利未知、个人毛利与阶段合计不一致。
禁止使用当前月份盈亏线替代原月份配置，禁止把待核算置零。
本次仅改变报表估算，不写历史订单、毛利快照或审批状态。
